# Herdr Agent Picker

A keyboard-driven agent picker for Herdr, currently available as a preview.

The default branch is `main`. Preview implementation and development live on
the [`preview` branch](https://github.com/kungbi/herdr-agent-picker/tree/preview).

## Install the preview

Requires Herdr 0.9.1+, Python 3.11+ and fzf 0.73.1+ on macOS or Linux.

```sh
herdr plugin install kungbi/herdr-agent-picker --ref preview
```

See the [preview README](https://github.com/kungbi/herdr-agent-picker/blob/preview/README.md)
for dependencies, keybindings and usage. Versioned packages are published as
[GitHub prereleases](https://github.com/kungbi/herdr-agent-picker/releases).
